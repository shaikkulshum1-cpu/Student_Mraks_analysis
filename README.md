Student Marks Analysis



Project Description



The Student Marks Analysis project is developed using Python to analyze student marks and calculate the total, average, highest, and lowest marks.



Objective



The objective of this project is to practice Python programming, data processing, lists, loops, and basic statistical calculations.



Tools Used



\- Python



Project Implementation



1\. Create an empty list to store student marks.

2\. Use a "for" loop to collect marks from 5 students.

3\. Store the entered marks in a Python list using "append()".

4\. Calculate the total marks using "sum()".

5\. Calculate the average marks by dividing the total by the number of students.

6\. Find the highest marks using "max()".

7\. Find the lowest marks using "min()".

8\. Display all the results using "print()".



Features



\- Accepts marks from 5 students.

\- Stores marks in a Python list.

\- Calculates total marks.

\- Calculates average marks.

\- Identifies the highest marks.

\- Identifies the lowest marks.

\- Validates marks between 0 and 100.

Conclusion



This project demonstrates the use of Python lists, loops, user input, built-in functions, and basic statistical calculations to analyze student marks.
